# Анализ оттока клиентов банка

## Бизнес-задача
Банк теряет клиентов. Нужно понять, кто уходит, почему и как это предотвратить.

## Стек
- Python (pandas, numpy, scikit-learn)
- SQL
- Streamlit (дашборд)

## Структура проекта
- `data/` — данные
- `notebooks/` — Jupyter-ноутбуки с анализом
- `sql/` — SQL-запросы
- `dashboard/` — дашборд
- `images/` — графики
